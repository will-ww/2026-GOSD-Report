## 关键口径

1. 主统计期为 2025-07-01 至 2026-06-30；历史为对应报告年度。
2. **五域中国 2026 年按作者更正取约 350 万**。2022—2025 年保留；原始 CSV 保留旧值，覆盖规则与重算结果在 `data/scenarios.json`。该值不替换地图 GitHub 口径的约 250.48 万。
3. 旧本土补充约 120 万单列，未与 GitHub 或五域直接相加；三者关系仍需核定。
4. 年均增长由 2022、2026 端点计算。延续路径保持该增速；放缓路径每年增速再乘 0.8。0.8 为预设敏感性参数，不是统计拟合。阴影不是置信区间，没有情景概率。
5. 2030 是以报告年度为锚的条件情景；短期行动从真实发布日期 T0 起计。没有把统计期末当成发布日期。
6. v0.2 图表统一采用四舍五入，排序与运算使用未舍入值；原数据未改。因而少数展示末位与 v0.1 的截断方式相差 0.01 万。
