# 第一章矢量信息图

七张 SVG 对应第一章 v0.4 第 3—8 页，裁自同一绘制结果，文字为路径。图形源由 `build_infographics.py` 与基础绘图脚本维护；不要单独修改导出图而造成正文不一致。

- `china-models-global-reuse.svg`：第 3 页中国模型与全球复用。
- `sdgs-dpg-public-capability.svg`：第 4 页。SDGs 来源 https://sdgs.un.org/goals；DPGA 要求来源 https://www.digitalpublicgoods.net/standard。DPGA 中文简述与改绘部分按 CC BY-SA 4.0，参见 https://creativecommons.org/licenses/by-sa/4.0/；四道门槛为本报告分析框架，不是两套体系的对应关系。
- `osdgs-framework.svg`：第 5 页，获批四支柱十维与原品牌母型。
- `osdi-framework.svg`、`six-entity-observation.svg`：第 6 页，候选指标结构及关联对象示意。
- `participation-contribution-influence.svg`：第 7 页，说明性案例，非实测网络。
- `four-evidence-perspectives.svg`：第 8 页，全书四视角。

统计来源、窗口与限定说明应随正文图题一同使用，不能将脱离语境的图件当作独立统计认证。
