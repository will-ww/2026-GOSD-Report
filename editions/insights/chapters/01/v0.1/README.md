## 可编辑文件与构建

chapter1.tex 为页面和正文；layout.sty 为中文排版；build_figures.py 依据 sources/chart-data.json 与根目录批准品牌注册表生成 figures/ 中的七组图件。prepare_assets.py 读取仓库外 2026 母稿，重建章首页并导出根目录批准标识。源码不内嵌 PDF 或字体。

本目录运行：

~~~bash
export GOSD_2026_SOURCE_PDF='/absolute/path/to/external-2026-mother-report.pdf'
bash build.sh
~~~

需要 XeLaTeX、fontspec、TikZ、Noto CJK SC、Liberation、Python 3、PyMuPDF、fontTools、Inkscape。母稿 SHA-256 固定为 675c3490c45d5fc4b51ca0c9ae2ddd5bb330abc108f148435d7317c221579a66。输出 PDF 在 output/，局部资产在 .build/，均不入库。版式核验见 review/validation.json，证据与待核查项见 review/evidence.md。
