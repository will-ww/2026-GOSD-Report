## 文件与使用

- `source-updates/`：13 个实际修改后的 TEX、JSON、Python 和 SVG 文件，保持相对于仓库 `reports/print-v1.1/` 的路径。
- `changes.json`：本轮范围、排除项和修改前后指纹。指纹按 UTF-8 文本的 LF 换行计算，以兼容 Windows Git 检出。
- `prepare_sources.py`：核对父版本及修改前后指纹，导出修订涉及的第五章、第六章、附录与图 5-1 模块；不会覆盖原归档或已有工作副本。它是模块源码准备入口，不是全书 PDF 构建器。

在仓库根目录运行：

```sh
python editions/insights/distributions/shared/source-revisions/v1.8/prepare_sources.py --check
python editions/insights/distributions/shared/source-revisions/v1.8/prepare_sources.py
```

结果位于本目录被 Git 忽略的 `work/corrected-modules/`。副本中的历史 README、指纹和验证记录继续描述旧交付；本轮状态以本说明及 `changes.json` 为准。

这些模块不是完整 v1.7 源码，不能直接替换最新全书或整章 PDF。后续合稿必须保留 v1.7 的前置内容、八大变化专题、附录第 116 页证据索引、目录和导航，并逐项将本轮图文合入对应位置。已验收 PDF 的历史构建入口仍重建其原版本，不会自动套用尚未验收的修订。
