1. 地区、企业、基金会及部分项目固定总榜的实际起止时间；2016—2026 历史标签的覆盖范围；跃升榜两端窗口。

3. LF 固定范围中仅 233 个仓库具有完整 12 个月数据，不能外推基金会全部项目。缺月不补零，月均值不替代未经定义的年度指标。

6. 模型榜为 2026 年 6 月 ModelRank 月榜；下载、派生的统计窗与去重规则待核。ModelRank 与 OpenRank 不横向比较，榜单不等于开放许可或全面开源认证。

## 目录与复现

- `report.tex`、`content/`、`design/`：LaTeX 正文、版式和品牌映射。
- `figures/`：实际引用的图件与新绘 SVG/PDF/PNG。
- `atlas/`：两张 A3 画像的 LaTeX 与素材。
- `sources/`：完整原始固定交付，保持原样。
- `provenance/`：规范、原正文、移出正文的来源记录及图号映射。
- `review/`：分页、字体、原值一致性、数据保留和最终验证记录；`contacts/` 为 40 页总览。
- `scripts/`：内容转换、图表重绘、核查与打包脚本。

依赖：XeLaTeX、Noto Sans/Serif CJK、Liberation 字体；Python 3 的 fonttools、PyMuPDF、Pillow，字体核查另需 Poppler 的 pdffonts。从已有图件编译执行 `bash build.sh`。字体从系统安装中提取至本地缓存并嵌入 PDF，缓存不随包分发。

如需从固定输入重生成图件，另需 Inkscape、pypdf，执行 `bash regenerate.sh`；该脚本也编译 PDF 并生成核查记录。建议在 Linux + TeX Live 环境复现。PDF 编译产物不进入 GitHub 仓库；本交付未执行仓库提交或网页发布。
