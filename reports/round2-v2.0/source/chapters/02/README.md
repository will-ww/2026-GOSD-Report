## 文件与复现

- `report.tex`、`content/`：当前LaTeX正文和逐页结构化内容。
- `modules/02/data/`：130个原始及派生数据文件，逐字节未变。
- `modules/02/figures/`：当前图件及转入配套的原始图件，SVG母版、PDF打印副本。
- `provenance/`：原始正文、原章末、迁移单元、来源清单、基线SVG及报告宪法。
- `review/`：核查说明、固定指纹、图号与稳定标签、自动验证结果。
- `scripts/`：整理、视觉导出、两图重绘及验证程序；`build.sh`构建当前PDF。

在安装XeLaTeX、Inkscape及Noto CJK字体的Linux环境执行`bash build.sh`。字体通过`configure_fonts.py`从系统提取供本地构建，不随包分发。若要重做图件导出，依次运行`draw_brand.py`、`restyle_figures.py`、`redraw_reading_diagrams.py`。正文再生成顺序为`prepare_chapter.py`、`refine_layout.py`。最终执行`verify_final.py`，并检查所有渲染页。

PDF与字体不提交GitHub。本包包含私有评审用图件PDF副本，后续仓库整理时遵照`.gitignore`排除。地球背景沿用批准资产，原生约128ppi；该项印前限制沿用品牌记录，正式印刷尚需高分辨率资产与色彩打样。
