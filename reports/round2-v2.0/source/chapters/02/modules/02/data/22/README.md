# 数据说明

原始字段、独立样本与派生计算分别保存。raw下的countries_236_value_extract.csv为236地贡献字段摘录，不是上游完整九字段CSV；countries_top35_excerpt.csv为上一版保留的前35地六字段摘录，平均值仅从这些同表数据计算。全球地图采用全部236地贡献字段匹配底图，未匹配项不作零。

五域序列与20条项目来源采用报告年度，地理快照为2025自然年。省级平均值选贡献总量前十后排序；province_average_original_top10.csv为原稿独立样本，仅保存，不混用。所有小数值保留，不擅自把上游估计数四舍五入后再进行计算。

prepare_data.py可再现全部派生值。源路径、上游对象身份、本地哈希和未解决问题见review目录。
