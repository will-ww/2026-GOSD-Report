# 世界底图说明

继承2.1 v0.1交付包中的Natural Earth 1:110m low resolution数据。原包来源登记为pyogrio测试资料中的Natural Earth摘录，并标注Public Domain。

许可入口：https://www.naturalearthdata.com/about/terms-of-use/

本轮未更改该套源文件。绘制阶段将CHN与TWN几何合并，不重复叠加中国数据；使用Equal Earth投影。小岛和部分地理项无法被低分辨率几何匹配，未匹配项不归零、不用任意位置补点。

这不是法定边界底图，正式出版仍需地图边界、审图和许可状态的复核。不要将此许可说明扩大到用户底稿中的中国地图图像或其他第三方材料。
