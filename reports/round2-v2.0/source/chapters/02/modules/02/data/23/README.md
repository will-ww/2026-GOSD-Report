# 数据身份

- countries_30_excerpt.csv：influence.json中全部30国数值字段摘录，非全量仓库/世界项目。
- companies_top6_excerpt.csv：该JSON企业榜前6字段，不是完整372企业表。
- china_projects_30_excerpt.csv：observations.json的chinaProjects字段全部30项。组织字段不改写、不作法律归属判断。
- five_groups_influence.csv：原稿CSV完整复制，Git blob SHA已核对。
- five_groups_contribution.csv：继承2.2底表，与本轮读取的observations序列复核。

数据截止与发布时间分别记录；2025自然年与2026报告年度不混算。派生数据以脚本复算，无模拟数字。当前公开标签未用于改变原统计对象或重算任何得分。
