## 文件与重建

- `report.tex`、`content/`：当前书稿和结构化全景对象。
- `design/`、`figures/`、`assets/`：母版、矢量图和真实标识资产。
- `sources/`、`provenance/`：前轮原始输入、权威文档和公开核查档案；旧分析不属于当前评审正文。
- `review/`：逐页清单、缩略总览、字体、几何、身份保全与链接检查。
- `scripts/draw_brand.py`、`scripts/draw_atlases.py`：重绘母版和七张全景；全景数据已冻结，无须联网即可重绘。
- `build.sh`：在具备XeLaTeX、Noto CJK、Liberation字体、Python/PyMuPDF的Linux环境中编译PDF。重绘另需Inkscape与Pillow。`configure_fonts.py`从系统字库提取简体中文字体，PDF嵌入字形。
- `scripts/finalize_pdf.py`：恢复逐条链接并添加全景页码；`scripts/check_render.py`导出逐页检查图和检查结果。

源码包不包含可重建的字体缓存、编译临时文件及单页高分辨率预览；交付PDF另行提供。未将PDF写入GitHub仓库。
