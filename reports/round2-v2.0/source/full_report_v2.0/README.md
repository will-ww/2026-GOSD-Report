## 复现

需要 XeLaTeX、Inkscape、Poppler、Noto CJK、Python 3（PyMuPDF、Pillow、fonttools、numpy）。字体从系统安装中提取，不随源码分发。在解压后的根目录执行：

```bash
python3 ch6_appendix_v0.2/scripts/draw_appendix.py
bash ch6_appendix_v0.2/build.sh
bash full_report_v2.0/front/build.sh
python3 full_report_v2.0/assemble.py
python3 full_report_v2.0/verify_and_render.py
python3 full_report_v2.0/check_isolated_render.py
```

`full_inputs` 中四份章节 PDF 是本次合并的固定输入，不是向 GitHub 发布的文件。本包中的 PDF 仅用于离线复现与评审。
