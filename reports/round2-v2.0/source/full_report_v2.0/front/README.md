## 复现

需 Python 3、XeLaTeX、Inkscape、Noto CJK 字体，以及 fonttools、Pillow、PyMuPDF。运行 `bash build.sh` 生成评审PDF；运行 `python3 scripts/draw_cleanup.py` 重建本轮8个矢量图件（7张说明图与1张收束页），再运行构建脚本。

为确保已获批封面等图件保持原样，figures/包含印刷派生PDF及SVG源码。工作字体由 configure_fonts.py 从本机字体生成，不随包分发。work、output、.build_fonts为本地生成目录。provenance/preparation_once.py仅记录本次从统稿底稿迁移的步骤，不是重复构建入口。

PDF只用于本地与评审交付，不提交GitHub。若后续向仓库提交源码，应遵守.gitignore，不加入任何PDF、生成字体或临时渲染文件。
