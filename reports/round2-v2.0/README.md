## 仓库外依赖与复现边界

仓库保留的是可公开的文本、程序、数据摘要及不含嵌入位图的 SVG 子集，不是一个无需外部输入即可编译全部章节的工程。PDF 打印派生件、项目标识原件、地球装饰位图、历史外部材料和字体均未静默替换或重新绘制。

已有四个原始源码交付包可按清单指纹恢复到被忽略的本地工作目录：

```sh
python scripts/restore_local_archives.py --archive-dir /path/to/original-packages
```

恢复脚本不联网、不下载材料、不执行包内程序。它验证已登记 ZIP 的哈希、拒绝不安全路径，并在 `work/external-packages/` 中保留完整外部依赖。完整合稿包中的第二至第五章 PDF 是原合稿的固定输入；使用这些输入合稿，不等于从第五章排版源码重建。原包的构建步骤见 [合稿说明](source/full_report_v2.0/README.md)，需要系统字体、XeLaTeX、Inkscape、Poppler 和 Python 依赖。

本次未重新排版或修改报告结论，未运行完整书稿编译与逐页印刷验收。第五章若需实质修改图文版式，仍须恢复原工程或另行建立并审阅新工程。

历史制作脚本并非全部离线：例如第四章 `scripts/prepare_atlases.py` 可联网获取账户头像，并保留原制作日期。归档与 CI 不运行这些采集脚本；后续重建须先审查联网、素材权利和日期记录，不能把新抓取结果标成旧快照。章节源码包的版本身份按交付记录保存，本次未用重新编译证明其输出与最终固定 PDF 逐字节一致。
