本轮核查版式、页序、空白页、正文内容保留、字体嵌入、跨模块导航与方法引用，不重算各章统计数据。主统计期仍为 2025-07-01 至 2026-06-30，历史资料、期后观察和条件情景分别标注。

本次评审重点：章首页与正文衔接是否自然；双面翻阅与留白是否合适；正文和密集图表字号是否适合实际打印；方法归并及导航是否方便查阅。八个模块的内容和视觉评审通过后，再进行最终整书合稿和联动核对。

## 重建与质量记录

依赖 Python 3、PyMuPDF、NumPy、Pillow、fontTools、XeLaTeX、Noto Sans/Serif CJK SC、Liberation 字体。字体不随源稿分发，重建时从已安装字体提取。PDF 中使用的字体已嵌入。PDF.js 为本轮额外的独立渲染验证工具，不是报告生成的必要依赖。

```sh
python3 modules-v0.1/rebuild.py
python3 modules-v0.1/verify_modules.py
```

`print_config.py` 为页码、标题、章色、导航的单一配置；`prepare_front.py` 更新前置目录；`build_modules.py` 生成章首页、页眉页脚、方法页、封底并装配八模块。首次构建两次 XeLaTeX 编译，稳定辅助文件下可以用 `--incremental`。

`review/module-manifest.json` 记录最终页序和空白页，`review/pdf-text-patches.json` 记录附录重编号等文本变更，`review/body-retention.json` 记录原生正文片段，`review/preflight.json` 记录字体、内容保留与页面检查。页面总览另见 `review/contacts/`。独立检查发现的标题叠字和第一章旧附录名已修正后再次核验。
