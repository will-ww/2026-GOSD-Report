## 编辑与复现

需要 Python 3（Pillow、PyMuPDF、fontTools）、Inkscape、XeLaTeX 和 Noto CJK 字体。字体不打包；构建脚本从系统已安装字体生成临时字体。

依次执行：

```bash
python3 figures_v2.py
python3 write_content.py
python3 validate_v2.py
python3 render_v2.py
python3 package_review_v2.py
```

`figures_v2.py` 是十幅组合图的入口，`legacy51.py` 与 `legacy52.py` 提供上一稿经评审的几何、来源解析与绘图函数。实际正文由 `write_content.py` 与 `render_v2.py` 生成，结构化段落保存在 `data/content-v0.2.json`。`figures/*.svg` 是可编辑矢量图，`assets/logos/` 保留发布账号图标。`inputs/` 中为已冻结的历史输入；其中旧样本不参与本轮 889 条开放评价的统计。

## 核验与限制

`review/data-qa-v0.2.json` 记录 119 项一致性检查，包括样本与主体加总、模型 ID 唯一性、材料证据关联、月度合计、网络端点、跨国守恒与 ModelRank 席位。`review/figure-qa.json` 检查图中文字边界和重叠，最终另作逐页视觉检查；`review/pdf-qa-v0.2.json` 记录页面、字体、书签与文本检查。算术一致性不等于独立运行验证。

开放等级沿用来源严格模式，L 为累进材料完整性，O 为权利条件。`missing` 仅表示平台未找到充分证据；许可资格字段与文件状态不能混读。高完整定义为 L3—L5，高开放定义为 O2—O4，二者交集称“双高”，这不构成认证。

待核：公开平台样本筛选年度与统一截止日；正式标准全文及具体版本许可的适用；训练与评测独立复现；地理归属覆盖；普惠实施的成本、本地化、维护与结果。
