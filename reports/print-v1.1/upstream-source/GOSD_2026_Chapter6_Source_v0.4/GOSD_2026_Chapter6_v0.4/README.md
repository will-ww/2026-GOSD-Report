## 复现

依赖 Python（Pillow、PyMuPDF、fontTools）、XeLaTeX、Inkscape、Poppler 和 Noto Sans/Serif CJK 字体。

```bash
python build.py
python verify.py
```

`content.py` 保存正文与结构化映射；`figures.py` 保存可编程图件；`data/` 保存冻结数据；`provenance/` 保存证据定位；`review/` 保存检查记录。
PDF 输出到 `output/GOSD_2026_Chapter6_Review_v0.4.pdf`。`.build/` 的字体和矢量缓存由构建脚本生成，不收入源码压缩包。

复核范围包括六页逐页视觉检查、标题层级和位置一致性、正文与图件越界重叠、12/10/10 项结构、抽象旧表达清理、中文字体嵌入及关键数值一致性。编辑前后映射见 `provenance/editorial-v0.4.json`。
