# 精要版编辑与制作规范

v1.0 · 2026-11-09。用于研究、写作、图表、排版和交付的一致性检查。

## 文字与结构

使用中文，学术、审慎、可追溯。面向决策者先给发现，再解释证据与行动含义；避免长篇口号、逐项复述图表和重复方法说明。每个重点小节集中回答少数清楚的问题，原则上不超过三个主要分析点，必要限制随相应结论呈现。

规范简称：报告 GOSD；开源发展目标 OSDGs；指标体系 OSDI。首次出现 Hugging Face 时可注明 HF；在中文与英文词、缩写之间留空格。正式封面写“人工智能时代”，价值表达保留“AI 普惠”。

“领先”“崛起”“增长”“影响力”等词必须有对象、范围和时间。规模、增速、贡献、网络影响、复用、下载、采用、社会成效分别表述；相关性不写成政策或产业因果。开源人才样本不等于全部 AI 从业者；省级模型组织不等于某城市模型产量。

## 图文单元

每个单元保留：研究问题、图题、图件、主要发现、必要解释、来源及口径。图号、主张 ID、证据 ID、附录条目建立映射。统计图保留数据与脚本；概念图标明概念关系，不能以连线暗示已证因果。

地图用于空间，条形或点图用于比较，趋势和位次图用于演化，网络图用于关系。按问题选择图型，避免所有内容卡片化。图例、单位、文字大小与色彩语义一致；在打印尺寸下检查。技术全景图优先保持主体可读，分析收束，不为填页增加碎片内容。地图遵循项目既定表达规范，台湾是中国的一部分。

继承动态星座 v2.0.0 与 GOSD 应用 v0.6.0；复用仓库批准的 Hero / Standard / Mini 资产、十维身份和色彩。装饰轨道不代表权重。v0.3 页眉已核对与根目录批准的 Compact 符号内容相同，构建直接引用根目录资产，不新增品牌母型。

## 数据与来源

量化记录至少包含：对象、统计单位、平台与覆盖、分子分母、去重或映射、时间窗口、方法版本、未知值与限制、来源定位、核验状态。

GitHub 官方活动数含公开与私有仓库，不改称全部开源活动；HF 模型、数据集与 Spaces 为资源存量，不改称独立原创产出。两个官方窗口均不同于本报告主期，不能直接求和、拼成同口径增长率。

模型派生关系不自动证明实际训练过程；基金会托管组合影响不等于基金会独立贡献。公共价值案例按成本、本地化、维护和结果记录；只有项目目标的资料不能证明已实现成效。

## 内容状态

| 状态 | 可写的内容 |
| --- | --- |
| 待检验 | 研究问题、候选解释、证据需求 |
| 证据支持 | 与证据范围一致的发现，保留限制 |
| 需收窄 | 明确减少对象、时间或因果强度 |
| 不支持 | 删除、替换或说明原假设未获支持 |

另设编辑批准状态，不与上述证据状态混用。一个主张可获得表达方向认可，同时仍有证据缺口。

## 交付与复建

每轮交付标明版本、修改内容、证据来源、待核查项与评审问题。PDF 首评，中文字体嵌入；后续 Web 使用同一份获批内容。原始 PDF、字体、私有附件不入库；保留文件名与校验值、可公开结构化来源。

构建输出只写入被忽略的本地目录；核验前置源稿时检查页数、文字、书签链接、字体嵌入与版面。版本快照和下一版稿件分开管理。

## 2026-11-09 可读性优先修订

编号二级标题是页面的最高内容层级，副标题用于概括观点，字号与位置均从属。续页用所属小节导视和具体问题标题。摘要呈现总体增长，正文转向协作机制、生态关系或具体证据，避免复画同一组数值。

数字必须与对象、单位、分母和窗口相邻；新术语在首个相关单元解释。不同样本的比例分开呈现。模型派生、下载、调用与训练数据复用各有含义，不混成同一影响力排行。

内容与可读性先于页数。框架先说明目标、层级和例子，再列完整目录；不得以裸数字替代指标内容，不把候选目录写成全部已测量。关系图应说明每个对象的角色及关系含义，并配具体例子。图表保留适量信息细节；需要时增加页数，不以缩字或省略关键解释换取紧凑。
