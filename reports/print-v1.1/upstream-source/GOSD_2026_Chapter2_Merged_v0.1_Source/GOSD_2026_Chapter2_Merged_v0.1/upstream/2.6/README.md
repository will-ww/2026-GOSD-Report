## 核心边界

期后快照：2026-11-09；样本仓库创建于 2021—2025 年；不是 2025.07—2026.06 主统计期数据。年份表示创建群体，文本来自同一快照。AI 提及不是实际采用率、代码生成比例、生产率或公共价值结果。行业标签是文本推断；不代表企业注册行业。未逐仓核验开源许可。

## 文件

- `data/content.json`：结构化正文、图题与来源、12 个分析点。
- `data/source/`：用户复现包中完整汇总表及分类评价结果。
- `data/sector_ai_trends_recovered.csv`：六行业 30 个分年点；来源及验证见 `data/recovery_provenance.json`。
- `figures/`：3 幅可编辑 SVG，中文文字保留为文本。
- `run.py`、`industry.py`、`appendix.py`、`build.py`、`layout.sty`：XeLaTeX 和矢量图构建源文件。
- `review/`：数值、版式和叙事复核结果；与摘要／第六章衔接的候选建议。
- `evidence/`：本轮已读取的宪法、主张地图、材料清单与编辑规范快照及来源索引。

## 构建

依赖 Python 3（Pillow、PyMuPDF、fontTools、NumPy），Inkscape、XeLaTeX 和系统 Noto Sans/Serif CJK 字体。

```sh
python run.py
```

正常构建直接读取已归档数据，不访问数据库、不训练模型，也不调用外部服务。临时字体与中间图 PDF 写入 `.build/`，最终 PDF 写入 `output/`。这些 PDF 不进入 GitHub。

`prepare_data.py` 为单独的曲线复核脚本，需要把原附件 `figures/figure3_sector_trends.pdf` 放入 `evidence/`。六组曲线用同图的全样本虚线校准坐标，结合行业分母恢复唯一整数分子；最大取整误差小于 0.00003 个仓库，六个 2025 端点与 CSV 完全一致。仍建议作者补归档原始行业分年表。源文件包不重复打包附件 PDF。
