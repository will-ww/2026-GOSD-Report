## 文件与复现

- `data/content.json`：六节最终结构化正文、图题、19 个图号与页码。
- `figures/`：19 幅可编辑 SVG。数值标注保持输入版本，少量标题改为更准确的表述。
- `upstream/`：各节所用结构化输入、原图和必要数据。2.4 只纳入人才有关材料。
- `chapter_pages.py`：导读、小结、统一附录及来源索引。
- `run.py`、`assemble_content.py`、`build.py`、`layout.sty`：XeLaTeX 编排和生成。
- `fix_pdf_text.py`：修复 Inkscape/Cairo 少量数字的 ToUnicode 映射，使文本可复制检索；不改变字形、数据或坐标。
- `review/`：数据复算、版面检查、跨章主张对照及本轮评审记录。

依赖：Python 3、PyMuPDF、Pillow、fontTools、Inkscape、XeLaTeX、Noto CJK SC 字体。字体从系统 Noto TTC 提取并嵌入。Linux 的典型执行方式为：

```bash
python3 run.py
python3 verify.py
```

`run.py` 只读取已保留的数据与 SVG，不需要连接数据库或联网，不包含数据库凭据。输出在 `output/`，完整 PDF 与附录 PDF 分别生成。源稿包不含 PDF、字体缓存或渲染截图。
