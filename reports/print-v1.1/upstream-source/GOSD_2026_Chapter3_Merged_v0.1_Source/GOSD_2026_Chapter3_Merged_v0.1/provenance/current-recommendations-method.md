# 十大战略建议：从证据到行动

v1.0 · 2026-11-09。目标为十条有执行主体和检验方式的建议，具体内容依十二项洞察与前瞻形成。

建议服务政府与国际组织，也覆盖企业、基金会、高校、研究机构、社区和地方伙伴。不要为每类主体平均分配条数，也不把维护责任全部交给志愿者。

每条至少记录：

| 字段 | 应回答的问题 |
| --- | --- |
| 对应问题与洞察 | 哪项已观察结构需要回应，证据及限制在哪里？ |
| 执行主体及伙伴 | 谁负责、谁参与、谁受益，是否包括本地伙伴？ |
| 具体行动 | 建立、调整、资助或停止什么，做到何种程度？ |
| 资源与约束 | 人员、资金、基础设施、许可、本地化和维护条件是什么？ |
| 时序 | 可立即开展、需要持续投入，或满足条件后启动？ |
| 结果指标 | 除发布数量外，如何观察复用、维护、能力与实际效果？ |
| 适用边界与复核 | 哪些地区或组织适用，何时调整？ |

“十项”是发布组织目标，不保证现有证据已经支持十个独立结论。相近行动合并；缺少依据的建议不伪装成实证结论。跨国或跨城差异应给条件化选择，不使用统一处方。

对应记录在 [data/recommendations.json](data/recommendations.json)。R01—R10 目前为空槽位，不提前虚构正文或审批结果。每条在进入正式稿前，至少链接一个已有证据的洞察，并说明从事实到规范建议之间的推理。

第四至第六章少量实施案例按成本、本地化、维护和结果四项检查；目标和宣传不能替代结果。政策、基金会安排等制度材料可以证明制度存在，不能单独证明实施效果。
