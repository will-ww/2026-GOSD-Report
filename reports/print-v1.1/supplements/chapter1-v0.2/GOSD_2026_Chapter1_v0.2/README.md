# GOSD 2026 第一章重构合稿 v0.2

本包供1.2和1.3的PDF评审及后续修改。包含章扉、已认可的1.1与本轮新增1.2、1.3。10页竖版，印刷页码10—19。

## 内容与来源

- `section12.py`：两页正文、图1-4和1-5的可编程源稿。
- `section13.py`：四页正文、图1-6、表1-1、图1-7和1-8。
- `data/`：正文、指标目录、来源、基线和文件哈希。
- `figures/`：带原生文字的可编辑SVG。
- `approved_11/`：前一轮1.1的图文源码和数据，作为已认可基线。
- `assets/approved-11.pdf`、`assets/approved-cover.pdf`：保持原样合入的报告自有基线页面。
- `review/`：本轮自检、待核定项、当前宪法与主张地图快照。

## 构建

安装Python3、PyMuPDF、Pillow、fontTools、XeLaTeX、Inkscape及Noto CJK字体后，在本目录运行`python run.py`。脚本生成新六页、合入基线，并输出`output/GOSD_2026_Chapter1_Review_v0.2.pdf`。

图件在PDF中为向量轮廓，以避免CJK字体子集缺字；SVG中的文字仍可编辑。正文由XeLaTeX排版并嵌入中文字体。构建缓存、字体文件和第三方原始报告不随本包分发。
