## 复现

依赖 Python 3、PyMuPDF、pypdf、Pillow、fontTools、XeLaTeX、Noto CJK 字体及 Poppler。保留源包其他目录，将已交付 v1.0 全文及 v0.1 前置 PDF 放到脚本指定路径后运行：

```sh
python3 institute-v1.1/build_page.py
python3 institute-v1.1/apply_revision.py
```

`build_page.py` 在缺少拆分字体时调用 `source/prepare_fonts.py`，从系统 Noto 字体集合提取 SC 字体，并生成单页及含页码的嵌入版。`apply_revision.py` 仅替换目标页内容与资源，保留其他页对象及导航。源包中的较早构建流程仍可重建原获批版本。本次 PDF 不提交 GitHub。
