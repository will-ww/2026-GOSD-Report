## 不包含的文件与重建边界

遵照仅放可编辑内容的要求，本次不提交 PDF、PNG/JPEG、字体、压缩包、编译产物及其他二进制文件。含内嵌 Base64 位图的 SVG 也整体排除，没有悄悄删去其中图片后冒充原图。排除清单见 `excluded-files.json`。

这是一份可编辑内容归档，不是无外部依赖的一键印刷重建包。现有装配程序依赖原章节 PDF、机构标识、背景图、字体及其他素材；这些未入库。源包内的原脚本可能仍引用 ZIP 或固定本地工作路径，使用时应以展开后的目录及本地素材位置调整。不得把本归档视为已重建全部 138 页或重新验收所有统计数据。

图 5-1 脚本需要 Python、Pillow、PyMuPDF、Noto 字体和 Inkscape。其他章节的原依赖和构建说明保留于各自目录。
