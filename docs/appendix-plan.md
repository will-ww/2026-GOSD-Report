# 附录规划与样节联动

v0.2实施规划 · 2026年11月4日

用户已明确要求将附录纳入整体设计。本文件沿用现有两篇附录的定位，细化其承载内容和与样节的关系；不是已完成的附录正文，也不替代证据复核。

## 编号沿革与宣言内容保留

现站存在导航残留不一致，不能据某一页菜单删除或新增附录。本轮读取结果如下：

|入口|所列结构|重构处理|
|---|---|---|
|全书目录及模型开放附录正文|附录A为方法，附录B为模型开放条件与数字公共品参照|作为当前正文结构起点，保留两篇附录|
|第六章菜单|A为方法、B为宣言、C为模型开放条件|记录历史编号，不按旧菜单重复创建相同内容|
|宣言来源页面|明确说明“来源说明已并入引言”，宣言全文收录于引言|宣言正文、来源与收录说明保留在引言；建立旧B到引言、旧C到现B的对应|

因此本规划采用当前A/B两篇结构，同时完整登记历史A/B/C三类内容，避免漏掉宣言及其来源。是否恢复宣言为独立附录是结构变更选项，未经另行评审不自动实施。后续发布检查须统一目录、章节导航、正文引用及下载入口中的编号；原正式站点本轮不修改。

## 附录A 指标 数据与研究方法

职责是让正文的定量发现能够被理解、核对和复用。保留现有A.1—A.8组织线索，在重构时集中登记以下内容：

- 指标定义、单位、分子分母、适用对象，以及参与、贡献、影响力的区分。
- 主统计期、历史比较窗口、期后观察及快照边界；数据获取时间和版本分别登记。
- 平台覆盖、机器人识别、账号去重、项目与仓库映射、组织归属和地域未知项的处理。
- 计算方法与实际实现版本、聚合规则、榜单筛选和技术分类；无法复算的上游结果如实说明。
- 模型供给、派生网络与开放材料样本的独立范围，不将不同快照拼成虚构时间序列。
- 缺失、零值、未覆盖与模拟的区分；跨期、跨平台和跨主体比较的条件。
- 图表与来源索引、数据及脚本版本、复核状态、可公开的复现路径。

正文图注至少保留对象、时期、样本范围与重要限制；附录承载较长的方法和查证细节。不能用附录引用替代关键图注。

## 附录B 模型开放条件与数字公共品研究参照

职责是使开放性与公共价值的表述有明确依据。保留现有B.1—B.6组织线索，集中维护：

- 本报告分类、外部开源定义和数字公共品正式认可之间的区别，以及各自适用对象。
- 固定模型版本、权重、代码、数据说明、许可和评估材料的证据记录；未知与不满足分开。
- 代表案例的选择理由、逐项判定依据、判断日期与限制，避免案例直接推及全部模型。
- 数字公共品标准和正式认可状态的查证入口；规范版本与查证日期必须固定。
- 从开放条件到复用、维护及社会成效的证据链；目标关联不自动等于已产生公共价值。
- 后续变更如何触发第五章分类、第一章概念和第六章建议的同步复核。

不得以附录名义作法律保证或机构背书；规范性判断与观察事实分别呈现。

## 六个样节如何同步补充附录

|样节|附录A同步内容|附录B同步内容|
|---|---|---|
|1.1|案例身份、日期、来源和证据强度；概念与实证的边界|开放协作、开放条件和公共价值的定义参照与案例限制|
|2.1|活跃判定、去重、地域覆盖、年度窗口和地图分母|仅在涉及开放条件或公共价值时建立明确参照，不强行加入|
|3.1|行政区划映射、影响算法、榜单范围、同分与跨期可比性|不将地区排名直接解释为治理或公共价值等级|
|4.1|技术分类版本、项目样本、协作关系和演化窗口|技术组件开放材料与许可条件的查证边界|
|5.1|模型与仓库/家族边界、发布时间、快照、去重与发布方归属|开放权重与完整开放的区别；涉及分类时链接固定证据|
|6.1|前文发现的主张和证据索引；期后观察与推演标记|行动建议所依赖的开放条件和公共价值证据边界|

样节先按既定顺序打磨；两篇附录同步形成相应条目，不另开与正文脱节的重复叙事。

## 最小可追溯记录

每项记录至少包含主张编号、正文/图表位置、附录条目、来源链接、对象和样本、数据时段、获取日期、指标与实现版本、核验状态及限制。附件或数据不可公开时提供可公开的说明，不上传私有原件或敏感数据。

验收时检查双向链接：正文的关键方法能够在附录定位，附录中的条目能够说明服务哪个正文问题。没有实际使用的技术细节不无条件扩充附录篇幅。
