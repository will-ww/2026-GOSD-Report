# 已获批报告应用页式

本目录保存GOSD v0.6.0所用的LaTeX页式与主装配文件，原文件逐字节保留。它们是完整审稿包的模板快照，不是独立正文工程。

复现32页原样稿时，应使用`approval.json`所登记的仓库外完整报告包：页式放在`report/design/gosd-atlas.sty`，装配文件放在`report/sample.tex`，品牌规范文件放在`brandbook/brandbook.tex`。保留其中既有正文、统计图和输入数据。不要用新生成的示例数据补缺。

后续新章节可以复用页式、章节入口和十维导视；图表必须继续遵守研究职责与证据规范。未迁入仓库的地球背景位图不能由占位图静默替换。PDF输出不得入库。
