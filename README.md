建议按以下顺序阅读：

1. [材料与版本清单](docs/material-inventory.md)：14项来源、版本身份、PDF校验值、17项图件索引和使用边界。

4. [评审决定清单](docs/review-checklist.md)：各轮已批准决定与下一阶段边界。

5. [附录规划](docs/appendix-plan.md)：方法、证据、开放条件参照与六个样节的联动。

候选主张必须经证据验证后才能作为正式发现；方向性基线获批不表示报告正文或样节已通过评审。
