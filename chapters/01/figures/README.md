# 第一章图件清单与复现

本目录由上级目录三个Python绘图程序动态生成：\`draw_report_figures.py\`、\`draw_chapter_figures.py\`、\`draw_sdgs_dpga.py\`。为遵守“PDF不入仓库”，只提交绘图程序和图表索引；本地运行\`make figures\`后生成SVG、PDF（用于XeLaTeX嵌入）及PNG（用于审阅），导出的PDF/PNG不入GitHub。

| 生成文件名 | 内容 | 位置/证据属性 |
|---|---|---|
| fig_book_structure | 六章四研究视角的阅读结构 | 章引 · 结构图 |
| fig_ai_open_landscape | 从代码协作到AI资源与角色扩展 | 1.1 · 概念示意 |
| fig_capacity_gates | 公共能力形成的四道关口 | 1.1 · 条件关系，非因果识别 |
| fig_sdgs_dpga | SDGs 17项目标与DPGA九项标准条件 | 1.1 · 规范参照，两侧不作逐项对应 |
| fig_osdgs_pillars | OSDGs X1—X4四支柱与观察维度 | 1.2 · 本报告目标框架 |
| fig_pillars_theme_matrix | 四支柱与第二章七主题联系 | 1.2 · 研究路径，不代表权重 |
| fig_osdi_logic | OSDI三级指标树与用途 | 1.3 · 方法示意；29项为候选 |

参考证据来源见\`../review/主张证据图表账本.md\`及\`../chapter1.tex\`末尾文献。非报告用户所提供的第三方图件原件未加入本目录。
