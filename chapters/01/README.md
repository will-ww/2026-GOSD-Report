# 第一章：从开放协作到公共价值

**章节基线：v1.2.0，2026-11-04，经作者认可**（非全书正式发布）。

本目录包含完整 1.1—1.3 LaTeX 正文、原创图表绘图程序、证据与修订记录。内容延续全书方向性基线 `fff392e957bab9fb6d89d49dea712af47484efaa`。正文主要以用户原始三份小节稿为母本；经过研究与图文审查后，采用 v1.2 作为后续编辑基线。

## 阅读与复现

- `chapter1.tex`：完整中文章节源码，含图题、交叉引用及章节参考文献。
- `draw_report_figures.py`：OSDGs支柱、全书结构和四支柱主题矩阵。
- `draw_chapter_figures.py`：智能开源、公共能力关口和OSDI观察逻辑。
- `draw_sdgs_dpga.py`：原创SDGs × 数字公共品标准双视角图。
- `figures/`：从绘图程序生成的矢量插图；不将导出的PDF图片入库。
- `review/`：主张—证据—图表账本、修订日志与未完成核查。
- 根目录 `docs/reviews/2026-11-04-chapter1-v1.2.md`：作者批准记录与版本指纹。

本稿需要 XeLaTeX、ctex、Noto CJK 字体，以及 Python matplotlib/numpy。中文字体只在构建环境安装，不复制字体文件至仓库。一般构建顺序：

```bash
python -m pip install -r requirements.txt
make figures
make pdf
```

**注意**：根目录宪法要求PDF不进入GitHub，包括章节评审PDF。上述命令仅在本地生成产物。文件内容不替代附录A的数据口径和附录B的开放性、数字公共品证据。

## 当前待核查项

1. 29项OSDI指标总表与分项表的术语、分母、样本、可操作性需逐项核验；目前称为候选指标。
2. 公共成效、治理事件和跨境复用仍按来源性质与适用范围区分，不能仅凭开放标签、下载或网络影响力推出社会收益。
3. 许可、国际协定原文及争议数字保留核查状态，不妨碍独立证据支持的后续研究。
4. 图件再利用需遵守来源许可及版本化来源说明；本章原创重绘不意味着第三方材料可直接再发行。
